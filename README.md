# Skouted League — Client Frontend

Production-ready, mobile-first Football Tournament Web Application built with React, Vite, and Tailwind CSS.

## Features
- **Live Match Center**: Zero-latency score updates, match ticker, and event feeds powered by Socket.io.
- **Standings & Statistics**: Dynamic championship table, group rankings, top scorers, and tournament assists.
- **Team Manager Portal**: Dedicated authenticated workspace for squad rosters, tactical lineup submissions, and matchday prep.
- **Player Registration & Accreditation**: Complete player profiling with live image preview, age auto-calculation, and duplicate jersey validation.
- **Admin Matchday Operator Console**: Isolated tournament administration panel for real-time fixture management, score controls, and team oversight.

## Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS (Dark athletic design system, `#00E676` pitch green accents)
- **Icons**: Lucide React
- **Real-Time Feeds**: Socket.io Client

## Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
